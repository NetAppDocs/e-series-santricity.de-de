= Import vertrauenswürdiger Zertifikate für Client-Controller im SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Wenn der Controller eine Verbindung ablehnt, weil er die Vertrauenskette für einen Netzwerkserver nicht überprüfen kann, kann ein Zertifikat von der Seite „Vertrauenswürdige Zertifikate“ importiert werden, das es dem Controller (der als Client fungiert) ermöglicht, die Kommunikation mit diesem Server zu akzeptieren.

.Bevor Sie beginnen
* Sie müssen mit einem Benutzerprofil angemeldet sein, das Sicherheitsadministratorberechtigungen enthält. Andernfalls werden keine Zertifikatfunktionen angezeigt.
* Die Zertifikatdateien werden auf Ihrem lokalen System installiert.


.Über diese Aufgabe
Das Importieren von Zertifikaten von der Seite „Vertrauenswürdige Zertifikate“ kann erforderlich sein, wenn einem anderen Server die Kontaktaufnahme mit den Controllern ermöglicht werden soll (zum Beispiel einem LDAP-Server oder einem Syslog-Server, der TLS verwendet).

.Schritte
. Im linken Bereich Menü:Zertifikate[Vertrauenswürdige Zertifikate] auswählen und anschließend *Import* wählen.
+
Es wird ein Dialogfeld zum Importieren der vertrauenswürdigen Zertifikatdateien geöffnet.

. Klicken Sie auf *Durchsuchen*, um die Zertifikatdateien für die Controller auszuwählen.
+
Die Dateinamen werden im Dialogfeld angezeigt.

. Klicken Sie Auf *Import*.


.Ergebnisse
Die Dateien werden hochgeladen und validiert.
