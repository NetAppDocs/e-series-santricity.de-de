= Erfahren Sie mehr über Thin Volume Monitoring in der SANtricity-Software
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können Thin Volumes auf Speicherplatz überwachen und entsprechende Warnmeldungen generieren, um Kapazitätsüberkapazitäten zu vermeiden.

Thin-Provisioning-Umgebungen können mehr logischen Speicherplatz zuweisen, als ihnen physischer Speicher zur Verfügung steht. Über den Menüpunkt Storage[Thin volume monitoring] lässt sich überwachen, wie stark Ihre Thin Volumes wachsen, bevor sie das zugewiesene Kapazitätsmaximum erreichen.

Sie können die Ansicht „Thin Monitoring“ verwenden, um die folgenden Aktionen auszuführen:

* Legen Sie die Grenze fest, die die zugewiesene Kapazität einschränkt, auf die sich ein Thin Volume automatisch erweitern kann.
* Den Prozentsatz festlegen, bei dem eine Warnung (Warnschwelle überschritten) an den Benachrichtigungsbereich gesendet wird, der über das Glockensymbol in der oberen Ecke des Fensters verfügbar ist, wenn sich ein Thin Volume der maximal zugewiesenen Kapazitätsgrenze nähert.


Um die Kapazität eines Thin-Volumes zu erhöhen, erhöhen Sie dessen gemeldete Kapazität.

[NOTE]
====
System Manager bietet keine Option zum Erstellen von Thin Volumes. Wenn Sie Thin Volumes erstellen möchten, verwenden Sie die Befehlszeilenschnittstelle (CLI).

====
[NOTE]
====
Thin volumes sind auf den Speichersystemen EF80, EF50, EF600/EF600C oder EF300/EF300C nicht verfügbar.
