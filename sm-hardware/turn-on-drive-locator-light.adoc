= Schalten Sie im SANtricity System Manager eine Laufwerkssuchleuchte ein
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Auf der Seite Hardware können Sie die Locator-LED einschalten, um den physischen Standort eines Laufwerks im Speicher-Array zu finden.

.Über diese Aufgabe
Sie können einzelne oder mehrere Laufwerke finden, die auf der Seite Hardware angezeigt werden.

.Schritte
. Im linken Bereich Menü:Hardware[Laufwerke] auswählen.
. Um ein oder mehrere Laufwerke zu finden, führen Sie einen der folgenden Schritte aus:
+
** *Einzelnes Laufwerk* – Suchen Sie in der Abbildung das Laufwerk, das Sie im Array physisch positionieren möchten. Klicken Sie auf das Laufwerk, um dessen Kontextmenü anzuzeigen, und wählen Sie dann *Positionsanzeige aktivieren*.
+
Die Positionsanzeige des Laufwerks leuchtet auf. Wenn Sie das Laufwerk physisch gefunden haben, kehren Sie zum Dialog zurück und wählen Sie *Ausschalten*.

** *Mehrere Laufwerke* – Im Filterfeld einen physischen Laufwerkstyp und einen logischen Laufwerkstyp auswählen. Die Anzahl der Laufwerke, die den Kriterien entsprechen, wird ganz rechts im Feld angezeigt. Anschließend auf *Positionsanzeigen einschalten* klicken. Nachdem die Laufwerke physisch gefunden wurden, zum Dialog zurückkehren und *Ausschalten* auswählen.
