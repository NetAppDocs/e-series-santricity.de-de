= Ändern der Ansichtsreihenfolge der Regale im SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können die Reihenfolge der auf der Seite Hardware angezeigten Shelfs ändern, um sie der physischen Reihenfolge der Regale in einem Schrank anzupassen.

.Schritte
. Wählen Sie im linken Bereich Menü:Hardware[Controllers and components].
. Wählen Sie die Dropdown-Liste für ein Regal aus und wählen Sie dann *Reihenfolge ändern*, um die Reihenfolge der auf der Seite „Hardware“ angezeigten Regale zu ändern.
