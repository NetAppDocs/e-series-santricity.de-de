= Controller-Einstellungen im SANtricity System Manager anzeigen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können Informationen zu einem Controller anzeigen, z. B. den Status der Host-Schnittstellen, Laufwerksschnittstellen und Management-Ports.

.Schritte
. Wählen Sie im linken Bereich Menü:Hardware[Controllers and components].
. Führen Sie eine der folgenden Aktionen durch, um die Controller-Einstellungen anzuzeigen:
+
** Klicken Sie auf den Controller, um das Kontextmenü anzuzeigen, und wählen Sie dann *Einstellungen anzeigen*.
** Wählen Sie das Controller-Symbol aus (neben der Dropdown-Liste *Shelf*). Wählen Sie bei Duplexkonfigurationen entweder *Controller A* oder *Controller B* aus dem Dialogfeld aus, und klicken Sie dann auf *Weiter*.
+
Das Schiebemenü für die Controller-Einstellungen wird geöffnet.



. In den Abschnitten finden sich Informationen zum Wechsel zwischen den Controller-Eigenschaftseinstellungen.
+
.Felddetails
[%collapsible]
====
[cols="25h,~"]
|===
| Abschnitt | Beschreibung 


 a| 
Details
 a| 
Zeigt den Controller-Status, Datum/Uhrzeit, Modellnamen und die Teilenummer des Ersatzteils an.



 a| 
Aktuelle Konfiguration
 a| 
Zeigt die aktuelle Firmware-Version und NVRAM Version.



 a| 
Datencache
 a| 
Zeigt die Gesamtsummen des Daten-Caches.



 a| 
Daten-Cache-Module
 a| 
Zeigt Speicherort, Status und Kapazität des Cache-Moduls an.



 a| 
Prozessorcache
 a| 
Zeigt die Gesamtsummen des Prozessor-Caches an.



 a| 
Cache Backup-Geräte
 a| 
Zeigt Standort, Status und Kapazität des Cache-Backup-Geräts an.



 a| 
Host-Schnittstellen
 a| 
Zeigt Informationen zur Host-Schnittstelle und zum Verbindungsstatus für jeden Port an.



 a| 
Laufwerksschnittstellen
 a| 
Zeigt Informationen zur Laufwerksschnittstelle und zum Verbindungsstatus für jeden Port an.



 a| 
Einstellungen für den Management-Port
 a| 
Zeigt Details zum Management-Port an, einschließlich Controller-Hostname, Remote-Login und IP-Netzwerkeinstellungen.



 a| 
Domain Name System (DNS)-Server-Einstellungen
 a| 
Zeigt die DNS-Konfiguration, den primären DNS-Server und den Backup-DNS-Server.



 a| 
Netzwerkzeitprotokoll (NTP) Servereinstellungen
 a| 
Zeigt Details zur NTP-Service- und NTP-Serverkonfiguration an.

|===
====
. Klicken Sie Auf *Schließen*.
